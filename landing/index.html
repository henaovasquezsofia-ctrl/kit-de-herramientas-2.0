Kit de consultorio

Herramientas psicológicas para psicólogos independientes

Herramientas

Consentimiento informado

Genera documentos de consentimiento informado con datos del profesional, encuadre terapéutico, honora­rios, políticas de cancelación y confidencialidad.

Ver herramienta

Notas de sesión

Organiza notas de sesión en formato estructurado (S-O-A-P): motivo, observaciones, intervenciones y plan. Guarda archivos locales automáticamente.

Ver herramienta

Tareas entre sesiones

Genera tareas o ejercicios personalizados entre sesiones según el objetivo terapéutico (ansiedad, sueño, manejo del enojo, hábitos saludables).

Ver herramienta

Agente de terminal

Un agente sencillo por consola. El usuario escribe lo que necesita, el agente decide cuál de las 3 herramientas usar, pide los datos que falten y devuelve el resultado. Sin Telegram, sin servidores, sin interfaz externa.

Ver documentación

Skills de apoyo

Ética y confidencialidad

Principios de confidencialidad y límites éticos para la práctica psicológica. Apoyo en la identificación de información sensible y recordatorio de los límites de confidencialidad.

Ver SKILL.md

Lenguaje empático

Transformación de lenguaje técnico o formal a un tono más empático y cálido, manteniendo el profesionalismo en la comunicación con consultantes.

Ver SKILL.md

Redacción profesional

Normalización de texto a formato profesional: corrección de informalidades, terminología psicológica estandarizada y formato coherente para documentos y informes.

Ver SKILL.md

Cómo usarlo

  1. Clona o descarga este repositorio.
  2. Ejecuta python3 kit.py en la terminal para acceder al menú principal.
  3. Selecciona una herramienta (1: consentimiento, 2: notas de sesión, 3: tareas entre sesiones).
  4. Sigue las instrucciones en pantalla para generar documentos, notas o tareas.
  5. Los resultados se guardan como archivos de texto en el directorio correspondiente.
